# Altium MCP Suite

**[English](../README.md) · [فارسی](README.fa.md) · [简体中文](README.zh-CN.md)**

[![Suite tests](https://github.com/M-R-Abedini/Altium-MCP-Suite/actions/workflows/tests.yml/badge.svg)](https://github.com/M-R-Abedini/Altium-MCP-Suite/actions/workflows/tests.yml)

دستیار هوش مصنوعیِ سازگار با MCP را برای کار روی شماتیک، PCB و کتابخانه به Altium Designer متصل کنید. این مجموعه سه سرور متن‌باز را با اجرای هماهنگ اسکریپت‌ها، بازیابی اتصال و کنترل صریح اتصال پایه‌ها کنار هم قرار می‌دهد.

**Windows · اتصال زنده آزمایش‌شده روی Altium Designer 26 · Python 3.12**

## قابلیت‌ها

| بخش | امکانات |
| --- | --- |
| شماتیک | خواندن قطعات و نت‌ها، قرار دادن و ویرایش اشیا، ساخت شماتیک از طرح ساختاریافته و بررسی اتصال و چیدمان |
| PCB | خواندن هندسه و قوانین، جانمایی قطعات و مس، برنامه‌ریزی مسیر و محاسبهٔ عرض ترک، امپدانس و بودجهٔ طول |
| کتابخانه | ساخت و ویرایش نماد و فوت‌پرینت؛ تطبیق هندسهٔ فوت‌پرینت با مشخصات land pattern استخراج‌شده از منبع سازنده |
| اتصال‌ها | snapshot پایه و نت، کنترل نت مورد انتظار و NC عمدی، مقایسهٔ نسخه‌ها و تطبیق پایه‌های شماتیک با پدهای PCB |
| بررسی و خروجی | پیش‌نمایش تصویری، گزارش بررسی و BOM؛ اجرای Output Jobهای Altium |

نام کامل نت‌های سلسله‌مراتبی در کنترل اتصال حفظ می‌شود و ورودی نامعتبر رد می‌شود. دادهٔ ناقص، حتی اگر اتصال‌های موجود درست باشند، نتیجهٔ قبول نمی‌گیرد. [نمونه‌ها و شرایط ورودی](../CONNECTIVITY_VERIFICATION.md) را ببینید.

## تفاوت با استفادهٔ جداگانه از MCPهای اصلی

ابزارهای طراحی از پروژه‌های موجود در مجموعه می‌آیند. امکانات اضافه‌شدهٔ این مخزن، نصب مشترک، هماهنگی اجرا و چهار ابزار کنترل اتصال هستند.

| استفادهٔ جداگانه از پروژه‌ها | این مجموعه |
| --- | --- |
| ورودی‌ها و تنظیمات مستقل | یک نصب Windows برای تولید تنظیمات MCP JSON و Codex TOML |
| مدیریت اجرای اسکریپت توسط هر پل Python | قفل مشترک و تحویل کنترل موتور اسکریپت Altium بین دو پل |
| چرخهٔ اتصال مستقل هر پل | بررسی سلامت و بازیابی محافظت‌شده؛ فرمان ویرایشِ timeoutشده خودکار تکرار نمی‌شود |
| ابزارهای بررسی پراکنده | یک روند برای snapshot، قرارداد پایه‌ها، مقایسهٔ اتصال و تطبیق دوسویهٔ شماتیک و پد PCB |
| سورس و راهنمای تست مستقل | ثبت commit منابع، حفظ مجوزها و CI در سطح مجموعه |

این مقایسه مربوط به snapshotهای موجود در مخزن است؛ ادعایی دربارهٔ تمام نسخه‌های فعلی MCPهای دیگر ندارد. پروژه‌های اصلی مستقلاً هم قابل استفاده‌اند:

| پروژه | نقش | مجوز |
| --- | --- | --- |
| [eda-agent](../eda-agent/README.md) | ابزار اصلی کنترل شماتیک، PCB و کتابخانه | Apache-2.0 |
| [coffeenmusic/altium-mcp](../coffeenmusic/README.md) | فرمان‌های تکمیلی Altium از طریق پل قدیمی | MIT |
| [altium-designer-mcp](../altium-designer-mcp/README.md) | سرور مستقل Rust برای عملیات فایل‌های کتابخانهٔ Altium | GPL-3.0-or-later |

نشانی مخزن و commit دقیق هر منبع در [UPSTREAM.json](../UPSTREAM.json) ثبت شده است.

## شروع کار

Git، Python 3.12 و Altium Designer را روی Windows نصب کنید. عملیات زندهٔ طراحی به نصب قابل‌اجرای Altium نیاز دارد.

```powershell
git clone https://github.com/M-R-Abedini/Altium-MCP-Suite.git
Set-Location Altium-MCP-Suite
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe setup.py --altium-exe "C:\Program Files\Altium\AD26\X2.EXE"
```

مسیر واقعی executable نرم‌افزار را وارد کنید. نصب‌کننده فایل‌های `mcp.local.json` و `codex.local.toml` را می‌سازد؛ بخش‌های لازم را در تنظیمات کلاینت ادغام و اتصال‌های MCP را دوباره راه‌اندازی کنید. تنظیمات قبلی کلاینت بازنویسی نمی‌شوند.

پروژه را در Altium باز کنید و پیش از ویرایش از دستیار بخواهید `app_context` را اجرا کند؛ سند فعال و وضعیت پل و اسکریپت گزارش می‌شود. از ورودی‌های هماهنگ‌شدهٔ تولیدشده استفاده کنید و نسخهٔ دیگری از پل‌های قدیمی را هم‌زمان اجرا نکنید.

### سرور اختیاری فایل‌های کتابخانه

سرور Rust جداگانه ساخته می‌شود. toolchain آن روی Rust 1.95.0 تثبیت شده و در Windows به ابزارهای ساخت C++ ویژوال استودیو نیاز دارد.

```powershell
Push-Location altium-designer-mcp
cargo build --release --locked
Pop-Location
.\.venv\Scripts\python.exe setup.py --altium-exe "C:\Program Files\Altium\AD26\X2.EXE" --library-dir "D:\MyProject\Libraries"
```

مسیر کتابخانه باید یک پوشهٔ موجود باشد. گزینهٔ `--library-dir` قابل تکرار است و سرور کتابخانه را به تنظیمات تولیدشده اضافه می‌کند. executable در `altium-designer-mcp/target/release/altium-designer-mcp.exe` ساخته می‌شود.

### معرفی ابزارها با مصرف کمتر context

اگر کلاینت تمام schemaهای ابزارها را وارد context می‌کند، `--toolset` و `minimal` را به فهرست آرگومان‌های **eda-agent** در تنظیمات تولیدشده اضافه کنید. دو ابزار `tool_catalog` و `tool_invoke` برای کشف و اجرای ابزارها معرفی می‌شوند و دسترسی به کل مجموعه حفظ می‌شود. برای غیرفعال‌کردن داشبورد بررسی محلی، `--no-dashboard` را اضافه کنید.

## حدود عملکرد

- کنترل زندهٔ Altium مخصوص Windows است و روی AD26 آزمایش شده؛ نسخه‌های دیگر Altium در این مجموعه تأیید نشده‌اند.
- پنجرهٔ modal می‌تواند پل را مسدود کند. پیش از تلاش دوباره، پنجره را تکمیل یا ببندید. پس از timeout فرمان ویرایش، ابتدا طراحی را بررسی کنید؛ ممکن است تغییر اعمال شده باشد.
- گزارش اتصال بدون ایراد، تأیید ERC/DRC، هندسهٔ فوت‌پرینت، اتصال واقعی مس یا آمادگی ساخت نیست. کامل‌بودن و تازه‌بودن داده باید توسط فراخواننده مشخص شود.
- بعضی ابزارها تغییر را برنامه‌ریزی یا محاسبه می‌کنند و بعضی آن را اعمال می‌کنند. نتیجه و محدودهٔ هر ابزار را بخوانید. این مجموعه تضمین طراحی کاملاً خودکار و آمادهٔ ساخت نیست.

## مستندات و اعتبارسنجی

- [کنترل اتصال](../CONNECTIVITY_VERIFICATION.md): ورودی‌ها، نمونه‌ها و معیارهای پذیرش.
- [گزارش بررسی](../REVIEW.md): شواهد انتشار و محدودیت‌های تأییدشده.
- [تغییرات محلی](../MODIFICATIONS.md): تغییرات پروژه‌های اصلی.
- [گردش‌کار CI](../.github/workflows/tests.yml): تست‌های Python و Rust.

از ریشهٔ مخزن اجرا کنید:

```powershell
.\.venv\Scripts\python.exe -m pytest tests eda-agent/tests/design/test_connectivity_contracts.py -q
.\.venv\Scripts\python.exe tests/smoke_stdio.py
```

تست stdio، راه‌اندازی سرورها و چهار ابزار اتصال را کنترل می‌کند. حالت اختیاری `--live` پل Altium باز را متوقف و بازیابی می‌کند؛ آن را پس از پایان عملیات جاری اجرا کنید. CI تمام ابزارها را روی یک نشست زندهٔ Altium اعتبارسنجی نمی‌کند.

برای گزارش مشکل قابل‌بازتولید، [issue ثبت کنید](https://github.com/M-R-Abedini/Altium-MCP-Suite/issues) و نسخهٔ Altium، نام ابزار، مراحل بازتولید و خطای دریافت‌شده را بنویسید.
