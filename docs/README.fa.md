# Altium MCP Suite

[English](../README.md) · [فارسی](README.fa.md) · [简体中文](README.zh-CN.md) · [العربية](README.ar.md)

</div>

<div dir="rtl">

سرورهای <span dir="ltr"><code>MCP</code></span> که به هوش مصنوعی اجازه می‌دهند شماتیک، برد و کتابخانه‌های آلتیوم شما را بخواند و ویرایش کند. آلتیوم باز می‌ماند و هوش مصنوعی روی همان پروژه‌ای که باز است، زنده کار می‌کند.

**پیش‌نیاز:** ویندوز و <span dir="ltr"><code>Python 3.12</code></span>. به‌صورت زنده روی <span dir="ltr"><code>Altium Designer 26</code></span> تست شده است.

## چه کارهایی می‌کند

- خواندن و ویرایش شماتیک باز: اضافه کردن قطعه، سیم‌کشی، گذاشتن لیبل نت و پورت تغذیه، ویرایش پارامترها، گرفتن <span dir="ltr"><code>BOM</code></span> و نت‌لیست.
- کار روی برد: جابه‌جایی قطعات، کشیدن ترک و ویا، کنترل فاصلهٔ چیدمان، پنلایز.
- ممیزی طرح: لیبل نت بی‌صاحب، پورت شناور، پین وصل‌نشدهٔ آی‌سی، خازن دی‌کاپلینگ جاافتاده، تداخل دیزاینیتور، قطعهٔ خارج از گرید — یا یک جاروی <span dir="ltr"><code>lint</code></span> با ۳۱ کنترل روی شماتیک و برد.
- بررسی اتصال با چهار ابزار فقط‌خواندنی: اسنپ‌شات نگاشت پین به نت (با دایجست <span dir="ltr"><code>SHA-256</code></span>)، قرارداد هر پین (نت مورد انتظار، یا وصل‌نبودن عمدی با ذکر دلیل)، مقایسهٔ قبل و بعد، و تطابق دوطرفهٔ پدهای شماتیک و برد.
- محاسبهٔ عرض ترک، امپدانس و بودجهٔ طول. این‌ها ماشین‌حساب‌اند، نه اثبات یکپارچگی سیگنال.
- خواندن و نوشتن فایل‌های کتابخانهٔ <span dir="ltr"><code>.SchLib</code></span> و <span dir="ltr"><code>.PcbLib</code></span>.
- دو پل، یک موتور اسکریپت: یک قفل مشترک نمی‌گذارد دو پل پایتون سر موتور اسکریپت آلتیوم دعوا کنند، و هر درخواست یک شناسه دارد تا پاسخ دیررسیدهٔ یک درخواست قدیمی پذیرفته نشود.

## چه چیزهایی هنوز در حال توسعه است

- کمک به چیدمان: چیدمان دسته‌ای و کنترل فاصله‌ها کار می‌کند؛ ابزارهای دقیق‌تر چیدمان هنوز در حال تکمیل است.
- پایداری پل: هر کرش شناخته‌شدهٔ <span dir="ltr"><code>DelphiScript</code></span> یا رفع یا مهار می‌شود، ولی موارد جدید هنوز پیدا می‌شوند — این کار ادامه دارد.
- اعتبارسنجی فعلاً فقط روی <span dir="ltr"><code>Altium Designer 26</code></span> انجام شده؛ نسخه‌های دیگر هنوز تست نشده‌اند.

## محدودیت‌های فعلی

- خطا در ویرایش دسته‌ای ممکن است بخشی از تغییرات را باقی بگذارد؛ ثبت عملیات در یک مرحلهٔ بازگشت، بازگردانی کامل را تضمین نمی‌کند. پیش از ویرایش گسترده یک نسخهٔ پشتیبان ذخیره کنید.

- آزمایشی است. بعضی عملیات می‌توانند موتور <span dir="ltr"><code>DelphiScript</code></span> آلتیوم را کرش کنند و حلقه را متوقف کنند — قبل از اینکه هوش مصنوعی طرح را ویرایش کند، از آن بکاپ بگیرید.
- ذخیره و فرمان‌های داخلی آلتیوم ممکن است هنگام اجرای یک فرمان <span dir="ltr"><code>MCP</code></span> منتظر بمانند. حلقه حدود دو ثانیه پس از آخرین فرمان کاری موتور را آزاد می‌کند؛ پینگ پس‌زمینه این زمان را تمدید نمی‌کند. فرمان بعدی <span dir="ltr"><code>MCP</code></span> حلقه را خودکار راه می‌اندازد.
- در پارامترهای JSON سرور اصلی، نویسه‌های بالاتر از <span dir="ltr"><code>U+00FF</code></span> پیش از ارسال رد می‌شوند تا به علامت سؤال تبدیل نشوند؛ انتقال کامل یونیکد هنوز پیاده‌سازی نشده است.
- مسیرهای شبکه باید درایو مپ‌شده باشند؛ مسیر <span dir="ltr"><code>UNC</code></span> باز نمی‌شود.
- ابزار <span dir="ltr"><code>proj_sync_pcb</code></span> به گزینهٔ <span dir="ltr"><code>allow_modal=True</code></span> نیاز دارد؛ به‌روزرسانی برد از روی شماتیک همچنان دیالوگ تعاملی باز می‌کند.
- ابزارهای بررسی اتصال فقط تخصیص پین را چک می‌کنند، نه مس را. داده‌ای که به آن‌ها نداده‌اید را نمی‌بینند.
- دیالوگ باز، فرمان‌های اسکریپت را متوقف می‌کند؛ ابزارهای تشخیص دیالوگ از طریق <span dir="ltr"><code>Win32</code></span> در دسترس می‌مانند. هنگام پردازش فرمان قبلی، فرمان جدید ارسال نمی‌شود. پس از پایان مهلت انتظار، درخواست مصرف‌نشده حذف می‌شود؛ عملیات در حال اجرا قابل لغو نیست، بنابراین پیش از تکرار فرمان، طرح را بررسی کنید.

## نصب

[کنترل ارتباط و بازیابی دستی](review/TRANSPORT_FINDINGS_2026-10-08.md) توضیح می‌دهد پس از پایان مهلت فرمان یا خرابی موتور، مالکیت نامشخص اسکریپت چگونه بررسی و آزاد می‌شود.

گیت، پایتون و آلتیوم را روی ویندوز نصب کنید. مسیر فایل اجرایی را مطابق نصب خودتان بگذارید:

</div>

<div dir="ltr">

```powershell
git clone https://github.com/M-R-Abedini/Altium-MCP-Suite.git
Set-Location Altium-MCP-Suite
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe setup.py --altium-exe "C:\Program Files\Altium\AD26\X2.EXE"
```

</div>

<div dir="rtl">

ورودی‌های تولیدشده در <span dir="ltr"><code>mcp.local.json</code></span> یا <span dir="ltr"><code>codex.local.toml</code></span> را به تنظیمات کلاینت اضافه و اتصال‌ها را دوباره راه‌اندازی کنید. پروژه را در آلتیوم باز کنید و با <span dir="ltr"><code>app_context</code></span> وضعیت پل را بررسی کنید.

برای کاهش حجم معرفی ابزارها، گزینهٔ <span dir="ltr"><code>--toolset minimal</code></span> را به نصب یا اجرای سرور اصلی اضافه کنید. ابزار را با <span dir="ltr"><code>tool_catalog</code></span> و گزینهٔ <span dir="ltr"><code>with_schema=True</code></span> پیدا کنید و از طریق <span dir="ltr"><code>tool_invoke</code></span> اجرا کنید. همهٔ عملیات در دسترس می‌مانند؛ تعریف ورودی‌ها هنگام نیاز بارگذاری و مانند حالت کامل اعتبارسنجی می‌شود. [نتایج اندازه‌گیری](review/PERFORMANCE_2026-10-08.md).

</div>

<div dir="ltr">

```powershell
Push-Location altium-designer-mcp
cargo build --release --locked
Pop-Location
.\.venv\Scripts\python.exe setup.py --altium-exe "C:\Program Files\Altium\AD26\X2.EXE" --library-dir "D:\MyProject\Libraries"
```

</div>

<div dir="rtl">

سرور کتابخانه اختیاری است (به نسخهٔ پین‌شدهٔ راست و ابزارهای ساخت <span dir="ltr"><code>Visual Studio C++</code></span> نیاز دارد). برای چند پوشه، گزینهٔ <span dir="ltr"><code>--library-dir</code></span> را تکرار کنید.
